---
title: SQLite Store
description: Lightweight SQLite store for development, testing, and single-node deployments.
---

The `store/sqlite` package implements Chronicle's `store.Store` interface using the grove ORM with the SQLite driver. It requires no external database process, making it ideal for development, integration tests, and single-node deployments.

## Import

```go
import (
    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/sqlitedriver"
    _ "github.com/xraph/grove/drivers/sqlitedriver/sqlitemigrate" // Migrate needs the executor
    "github.com/xraph/chronicle/store/sqlite"
)
```

## Constructor

```go
drv := sqlitedriver.New()
if err := drv.Open(ctx, "chronicle.db"); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(drv)
if err != nil {
    log.Fatal(err)
}

s := sqlite.New(db)
```

For tests, point it at a file under `t.TempDir()`. Be careful with `":memory:"`: every pooled connection opens its own empty in-memory database, so tables `Migrate` creates on one connection can be missing on the next.

```go
drv := sqlitedriver.New()
if err := drv.Open(ctx, filepath.Join(t.TempDir(), "chronicle.db")); err != nil {
    t.Fatal(err)
}
db, err := grove.Open(drv)
```

## Migrations

Run schema migrations before first use. Migrations are idempotent: safe to run on every startup:

```go
if err := s.Migrate(ctx); err != nil {
    log.Fatal(err)
}
```

## Full setup with `chronicle.New`

```go
import (
    "context"
    "log"

    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/sqlitedriver"
    "github.com/xraph/chronicle"
    "github.com/xraph/chronicle/store"
    "github.com/xraph/chronicle/store/sqlite"
)

ctx := context.Background()

drv := sqlitedriver.New()
if err := drv.Open(ctx, "chronicle.db"); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(drv)
if err != nil {
    log.Fatal(err)
}

s := sqlite.New(db)
if err := s.Migrate(ctx); err != nil {
    log.Fatal(err)
}

adapter := store.NewAdapter(s)

c, err := chronicle.New(chronicle.WithStore(adapter))
```

## With the Forge extension

```go
import chronicleext "github.com/xraph/chronicle/extension"

ext := chronicleext.New(
    chronicleext.WithStore(s),
    chronicleext.WithUnauthenticatedAPI(), // or WithAuth(...); required while routes are on
    // Migrate runs automatically on Start unless WithDisableMigrate()
)
app.RegisterExtension(ext)
```

## Interfaces implemented

`sqlite.Store` satisfies:

- `audit.Store`
- `stream.Store`
- `verify.Store`
- `erasure.Store`
- `retention.Store`
- `compliance.ReportStore`
- `store.Store` (composite)

## Characteristics

| Aspect | Detail |
|--------|--------|
| Driver | grove ORM + sqlitedriver |
| Migrations | grove orchestrator with programmatic migrations |
| Concurrency | Multiple readers, single writer (WAL mode) |
| Persistence | File-based or in-process (`":memory:"`) |
| Recommended for | Development, integration tests, single-node deployments |
| Not recommended for | High-throughput multi-writer production workloads |

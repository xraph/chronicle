The `plugin` package defines hook interfaces and a `Registry` that sorts plugins by the hooks they implement and can emit each hook.

It isn't wired into Chronicle yet. `chronicle.New` takes no registry and `Record` never calls one, so `OnBeforeRecord`, `OnAfterRecord`, alert handlers and `SinkProvider` sinks don't run when you record an event, and the Forge extension doesn't build a registry either. To use plugins today, call the registry yourself around `Record`, as in [Driving the registry yourself](#driving-the-registry-yourself). The "fires when" lines below describe what each hook is for when you do that.

## Plugin base interface

Every plugin must implement `plugin.Plugin`:

```go
type Plugin interface {
    Name() string
}
```

Implement any additional interfaces below to opt into specific hooks.

## Hook interfaces

### `OnInit` / `OnShutdown`

```go
func (p *MyPlugin) OnInit(ctx context.Context) error { ... }
func (p *MyPlugin) OnShutdown(ctx context.Context) error { ... }
```

`registry.EmitInit(ctx)` and `registry.EmitShutdown(ctx)` call them.

### `BeforeRecord`

```go
func (p *MyPlugin) OnBeforeRecord(ctx context.Context, event *audit.Event) error {
    event.Metadata["server"] = "us-east-1"  // enrich
    return nil
}
```

`registry.EmitBeforeRecord(ctx, event)` calls it. Use for:
- Enrichment: add computed metadata fields
- Filtering: return `plugin.ErrSkipEvent`, and `EmitBeforeRecord` returns it so you can skip the `Record` call
- Transformation: modify any non-identity, non-hash field

### `AfterRecord`

```go
func (p *MyPlugin) OnAfterRecord(ctx context.Context, event *audit.Event) error {
    notify(event)
    return nil
}
```

`registry.EmitAfterRecord(ctx, event)` calls it, and checks the event against the registry's alert rules. Use for notifications, alerting, forwarding, metrics counters.

### `SinkProvider`

```go
func (p *MySinkPlugin) Sink() sink.Sink {
    return sink.NewS3Sink(s3Writer, "audit-bucket", "events/")
}
```

`registry.Sinks()` returns the sinks these plugins provide. Nothing in Chronicle writes to them.

### `AlertHandler`

```go
func (p *MyPlugin) OnAlert(ctx context.Context, event *audit.Event, rule *plugin.AlertRule) error {
    send(fmt.Sprintf("ALERT: %s fired for event %s", rule.Name, event.ID))
    return nil
}
```

`EmitAfterRecord` calls it when the event matches an alert rule set on the registry.

### `Exporter`

```go
func (p *MyPlugin) Format() string { return "ndjson" }
func (p *MyPlugin) Export(ctx context.Context, data any, w io.Writer) error { ... }
```

Meant to provide a custom export format for compliance reports. The compliance engine doesn't consult the registry, so it isn't used yet.

### `ComplianceReporter`

```go
func (p *MyPlugin) ReportType() string { return "pci-dss" }
```

Meant to provide a custom compliance report type. Not used yet, for the same reason.

## Hook interface summary

| Interface | Method | When |
|-----------|--------|------|
| `OnInit` | `OnInit(ctx)` | `registry.EmitInit` |
| `OnShutdown` | `OnShutdown(ctx)` | `registry.EmitShutdown` |
| `BeforeRecord` | `OnBeforeRecord(ctx, event)` | `registry.EmitBeforeRecord` |
| `AfterRecord` | `OnAfterRecord(ctx, event)` | `registry.EmitAfterRecord` |
| `SinkProvider` | `Sink()` | Once at registration; listed by `registry.Sinks()` |
| `AlertHandler` | `OnAlert(ctx, event, rule)` | `registry.EmitAfterRecord`, when an alert rule matches |
| `Exporter` | `Format() / Export(...)` | Nothing calls it yet |
| `ComplianceReporter` | `ReportType()` | Nothing calls it yet |

## ErrSkipEvent

Returning `plugin.ErrSkipEvent` from `OnBeforeRecord` makes `registry.EmitBeforeRecord` return `ErrSkipEvent`. Your code then skips the `Record` call; Chronicle doesn't drop anything on its own.

```go
func (p *MyPlugin) OnBeforeRecord(ctx context.Context, event *audit.Event) error {
    if event.Category == "debug" {
        return plugin.ErrSkipEvent
    }
    return nil
}
```

## Registry

```go
import "github.com/xraph/chronicle/plugin"

registry := plugin.NewRegistry(logger)
registry.Register(&MyPlugin{})
registry.Register(&MySinkPlugin{})

// Set alert rules
registry.SetAlertRules([]plugin.AlertRule{
    {Name: "critical-auth", Severity: "critical", Category: "auth"},
})
```

The registry inspects each plugin at `Register` time to determine which interfaces it implements, so emitting a hook doesn't type-assert every plugin again.

## Driving the registry yourself

Since `Record` doesn't call the registry, wrap it:

```go
func record(ctx context.Context, c *chronicle.Chronicle, registry *plugin.Registry, event *audit.Event) error {
    if err := registry.EmitBeforeRecord(ctx, event); err != nil {
        if errors.Is(err, plugin.ErrSkipEvent) {
            return nil // a plugin filtered it out
        }
        return err
    }
    if err := c.Record(ctx, event); err != nil {
        return err
    }
    registry.EmitAfterRecord(ctx, event)
    return nil
}
```

## Full example

```go
type EnrichmentPlugin struct{}

func (p *EnrichmentPlugin) Name() string { return "enrichment" }

func (p *EnrichmentPlugin) OnBeforeRecord(ctx context.Context, event *audit.Event) error {
    event.Metadata["region"] = "us-east-1"
    event.Metadata["version"] = "2.1.0"
    return nil
}

func (p *EnrichmentPlugin) OnAfterRecord(ctx context.Context, event *audit.Event) error {
    metrics.Counter("chronicle.events.recorded", 1, tag("category", event.Category))
    return nil
}

registry := plugin.NewRegistry(logger) // a github.com/xraph/go-utils/log Logger
registry.Register(&EnrichmentPlugin{})
```

title: Admin API
description: HTTP admin API for events, verification, checkpoints, erasure, retention, reports and stats.
---

The `handler` package exposes 24 REST endpoints on a Forge router, with full OpenAPI metadata. Routes are registered under `/v1`, and the Forge extension mounts them under its base path, so with the defaults the paths below are `/chronicle/v1/...`.

## Setup

The usual way to serve the API is the [Forge extension](/docs/guides/forge-extension), which builds the dependencies, guards and routes for you. To mount it on a Forge router yourself, after the extension has registered:

```go
// ext is the *extension.Extension you registered with WithDisableRoutes().
ext.RegisterRoutes(app.Router().Group("/audit"))
```

`handler.New(deps, router)` takes a `handler.Dependencies` and a `forge.Router`, not an `http.ServeMux`. `ext.Handler()` gives you the same routes as an `http.Handler` on a router of its own.

## Authentication

Every request needs an app ID on its context (Forge's scope, or `scope.WithAppID` from your own middleware); without one it gets `401 Unauthorized`. Queries are filtered by the tenant on the context too.

On top of that, routes are guarded per operation class. Read routes (listing, getting, verifying) need the read scopes, write routes (saving a retention policy, generating a report, forcing a checkpoint) need the write scopes, and admin routes (enforcing retention, deleting a policy, requesting an erasure) need the admin scopes. Configure them with `auth.*` or `WithAuth`. With routes on, the extension refuses to start until you configure auth or call `WithUnauthenticatedAPI()`, because a caller with only an app scope could otherwise purge that app's audit history.

{"error": "chronicle: event not found"}

## Events

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/events` | List events with filters (category, action, severity, outcome, time range) |
| `GET` | `/v1/events/:id` | Get a single event by ID |
| `GET` | `/v1/events/user/:userId` | Get events for a specific user |
| `POST` | `/v1/events/aggregate` | Grouped counts for analytics |

### List events query parameters

| Parameter | Description |
|-----------|-------------|
| `category` | Filter by event category |
| `action` | Filter by action verb |
| `severity` | `info`, `warning`, or `critical` |
| `outcome` | `success`, `failure`, or `denied` |
| `from` | Start time (RFC3339) |
| `to` | End time (RFC3339) |
| `limit` | Page size (default 20) |
| `offset` | Page offset |
| `order` | `asc` or `desc` |

## Verification

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/verify` | Verify hash chain integrity |

Request body:

```json
{
  "stream_id": "stream_01j9vk...",
  "from_seq": 0,
  "to_seq": 0
}
```

Response: `verify.Report`, with `valid`, `verified`, `gaps` and `tampered`.

## Checkpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/checkpoints` | List signed checkpoints |
| `GET` | `/v1/checkpoints/:id` | Get a checkpoint |
| `POST` | `/v1/checkpoints` | Force a checkpoint now (write) |

## Erasure

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/erasures` | Request GDPR erasure for a subject |
| `GET` | `/v1/erasures` | List erasure records |
| `GET` | `/v1/erasures/:id` | Get a specific erasure record |

## Retention

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/retention` | List retention policies |
| `POST` | `/v1/retention` | Create or update a retention policy |
| `DELETE` | `/v1/retention/:id` | Delete a policy |
| `POST` | `/v1/retention/enforce` | Trigger immediate retention enforcement |
| `GET` | `/v1/retention/archives` | List archive records |

## Reports

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/reports` | List compliance reports |

| `POST` | `/v1/reports/hipaa` | Generate HIPAA report |
| `POST` | `/v1/reports/euaiact` | Generate EU AI Act report |

## Forge extension

When using the Forge extension, routes are registered automatically during `Register` unless you pass `WithDisableRoutes()`:

```go
ext := chronicleext.New(
    chronicleext.WithStore(s),
    chronicleext.WithAuth("jwt", readScopes, writeScopes, adminScopes),
)
app.RegisterExtension(ext)
```

Access the underlying `handler.API` for manual control:

```go
ext.API().RegisterRoutes(customRouter) // a forge.Router
```

Or get an `http.Handler` serving the routes on a router of its own:

```go
h := ext.Handler()
http.ListenAndServe(":8080", h)
```

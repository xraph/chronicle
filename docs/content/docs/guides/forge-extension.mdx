title: Forge Extension
description: Mount Chronicle into a Forge application as a first-class extension.
---

Chronicle ships as a `forge.Extension` that integrates with the Forge framework's lifecycle, DI container, and router. This is the recommended approach for Forge applications.

## Register the extension

```go
import (
    "time"

    "github.com/xraph/forge"
    chronicleext "github.com/xraph/chronicle/extension"
    grove "github.com/xraph/grove/extension"
)

app := forge.NewApp(forge.AppConfig{
    Name: "billing-api",
    Extensions: []forge.Extension{
        grove.New(), // extensions.grove: driver and dsn
        chronicleext.New(
            chronicleext.WithAuth("jwt",
                []string{"chronicle:read"},
                []string{"chronicle:write"},
                []string{"chronicle:admin"},
            ),
            chronicleext.WithRetentionInterval(24 * time.Hour),
        ),
    },
})
```

List Grove first: Chronicle looks up the container's `*grove.DB` during `Register` and picks the PostgreSQL, SQLite or MongoDB store to match its driver. `app.RegisterExtension(ext)` works too, before the app starts.

The admin API can purge history, so with routes on the extension refuses to start until you configure an auth provider (`WithAuth` or `auth.provider`), allow unauthenticated access explicitly (`WithUnauthenticatedAPI()` or `auth.allow_unauthenticated: true`), or turn the routes off. Requests also need an app scope on the context (Forge's scope, or `scope.WithAppID` from your own middleware), or they get a 401.

During `Register` the extension:
1. Loads config from `extensions.chronicle` (or a top-level `chronicle` key) and builds the hash chain (plain or HMAC).
2. Picks a store (see [store resolution](#store-resolution-order)), wraps it with `store.NewAdapter` and builds `chronicle.New`.
3. Creates the compliance engine, the retention enforcer and the `handler.API`, wrapping the store with `sealedstore` when crypto-erasure is on.
4. Registers the admin routes under the base path (`/chronicle` by default) plus `/v1`, unless routes are disabled.
5. Provides `chronicle.Emitter` in the DI container.

`Start` runs `Migrate` on the store (unless `disable_migrate` is set), then starts the retention scheduler (when `retention_interval` is above zero) and the checkpoint scheduler (when checkpoints are enabled). `Stop` cancels both schedulers. `Health` pings the store.

## Receive the Emitter via DI

Other extensions receive the `chronicle.Emitter` interface from the DI container without importing Chronicle internals:

```go
import (
    "github.com/xraph/vessel"
    "github.com/xraph/chronicle"
)

type MyExtension struct {
    emitter chronicle.Emitter
}

func (e *MyExtension) Register(app forge.App) error {
    emitter, err := vessel.Inject[chronicle.Emitter](app.Container())
    if err != nil {
        return err
    }
    e.emitter = emitter
    return nil
}

func (e *MyExtension) doSomething(ctx context.Context) {
    e.emitter.Info(ctx, "action", "resource", "id").
        Category("myservice").
        Record()
}
```

## Access extension components

If you need direct access to Chronicle internals (e.g. to mount custom routes or run manual enforcement):

```go
// The Chronicle engine for direct record/query
c := ext.Chronicle()

// The Emitter (same as what DI provides)
emitter := ext.Emitter()

// The compliance engine
engine := ext.ComplianceEngine()

// The retention enforcer
enforcer := ext.RetentionEnforcer()

// The handler.API (for manual route registration)
api := ext.API()

// An http.Handler serving the same routes on a router of its own
h := ext.Handler()
```

## Disable automatic routes

If you want to mount routes on a sub-path or a different router:

```go
ext := chronicleext.New(
    chronicleext.WithStore(pgStore),
    chronicleext.WithDisableRoutes(),
)
app.RegisterExtension(ext)

// After Register: put the routes on a Forge router group of your own.
ext.RegisterRoutes(app.Router().Group("/audit"))
```

`ext.Handler()` returns the same routes as an `http.Handler` on a router of its own, at `/v1/...`.

## Disable automatic migrations

```go
ext := chronicleext.New(
    chronicleext.WithStore(pgStore),
    chronicleext.WithDisableMigrate(),
)
// Run migrations yourself before starting
if err := pgStore.Migrate(ctx); err != nil {
    log.Fatal(err)
}
app.RegisterExtension(ext)
```

## Grove database integration

When your Forge app uses the [Grove extension](https://github.com/xraph/grove) to manage database connections, Chronicle can automatically resolve a `grove.DB` from the DI container and construct the correct store backend based on the driver type.

### Using the default grove database

If the Grove extension registers a single database (or a default in multi-DB mode), use `WithGroveDatabase` with an empty name:

```go
ext := chronicleext.New(
    chronicleext.WithGroveDatabase(""),
)
```

### Using a named grove database

In multi-database setups, reference a specific database by name:

```go
ext := chronicleext.New(
    chronicleext.WithGroveDatabase("audit"),
)
```

This resolves the grove.DB named `"audit"` from the DI container and auto-constructs the matching store. The driver type is detected automatically, so you don't import the store packages yourself.

### Using the default grove KV store

If the Grove extension registers a KV store, use `WithGroveKV` with an empty name:

```go
ext := chronicleext.New(
    chronicleext.WithGroveKV(""),
)
```

### Using a named grove KV store

In multi-KV setups, reference a specific KV store by name:

```go
ext := chronicleext.New(
    chronicleext.WithGroveKV("chronicle-kv"),
)
```

### Store resolution order

The extension resolves its store in this order:

1. Explicit store: if `WithStore(s)` was called, it is used directly and grove is ignored.
2. Grove database: if `WithGroveDatabase(name)` was called (or `grove_database` is set in YAML), the named or default `grove.DB` is resolved from DI.
3. Grove KV: if `WithGroveKV(name)` was called (or `grove_kv` is set in YAML), the named or default grove KV store is resolved from DI, and the Redis store is built on it.
4. A default `grove.DB` in the container, if the Grove extension registered one.

There is no in-memory fallback. If none of these applies, `Register` fails with "no store configured".

## YAML configuration

The Chronicle extension automatically loads configuration from your Forge app's YAML config files. It looks for the key `extensions.chronicle` first, then falls back to `chronicle`:

```yaml
# forge.yaml (or app.yaml, config.yaml, etc.)
extensions:
  chronicle:
    base_path: /chronicle
    grove_database: audit
    enable_crypto_erasure: true   # also needs WithKeyStore
    retention_interval: 24h
    disable_routes: false
    disable_migrate: false
    auth:
      provider: jwt
      read_scopes: [chronicle:read]
      write_scopes: [chronicle:write]
      admin_scopes: [chronicle:admin]
```

Or at the top level:

```yaml
chronicle:
  grove_database: ""
  retention_interval: 24h
  auth:
    allow_unauthenticated: true   # local development only
```

### Configuration reference

| Field | YAML key | Type | Default | Description |
|-------|----------|------|---------|-------------|
| `GroveDatabase` | `grove_database` | `string` | `""` | Name of the grove.DB to resolve from DI; empty uses the default DB |
| `GroveKV` | `grove_kv` | `string` | `""` | Name of the grove KV store to resolve from DI; empty uses the default KV |
| `BasePath` | `base_path` | `string` | `"/chronicle"` | URL prefix for the admin API |
| `BatchSize` | `batch_size` | `int` | `100` | Loaded, but has no effect: `Record` writes each event synchronously |
| `FlushInterval` | `flush_interval` | `duration` | `1s` | Loaded, but has no effect, like `batch_size` |
| `EnableCryptoErasure` | `enable_crypto_erasure` | `bool` | `false` | Enable GDPR crypto-erasure (also needs `WithKeyStore`) |
| `Auth` | `auth.provider`, `auth.read_scopes`, `auth.write_scopes`, `auth.admin_scopes`, `auth.allow_unauthenticated` | | none | Who may call the admin API. Required while routes are on |
| `TamperEvidence` | `tamper_evidence.digest`, `tamper_evidence.keys.*` | | `plain` | `hmac` keys the chain; see [Verification](/docs/subsystems/verification) |
| `Checkpoints` | `checkpoints.enabled`, `every_events`, `every_interval`, `signer.*` | | off | Signed checkpoints |
| `RetentionInterval` | `retention_interval` | `duration` | `24h` | Retention enforcement interval (0 = off) |
| `DisableRoutes` | `disable_routes` | `bool` | `false` | Skip auto route registration |
| `DisableMigrate` | `disable_migrate` | `bool` | `false` | Skip `Migrate` on `Start` |
| `Dashboard.AppID` | `dashboard.app_id` | `string` | `""` | App a dashboard session takes when its claims carry no `app_id`. A present but unreadable claim is still refused, and so is a request with no signed-in user |
| `Dashboard.TenantID` | `dashboard.tenant_id` | `string` | `""` | Tenant the `dashboard.app_id` session takes when its claims carry no `tenant_id` or `org_id`. A session that claims its own app never takes it. Refused at startup without `dashboard.app_id`. Neither value may have edge whitespace or control characters |

## Full option reference

| Option | Default | Description |
|--------|---------|-------------|
| `WithStore(s)` | none | A `store.Store` backend. Optional when a grove database is available |
| `WithAuth(provider, read, write, admin)` | none | Forge auth provider and the scopes for each operation class |
| `WithUnauthenticatedAPI()` | off | Allow the admin API without auth (local development) |
| `WithBatchSize(n)` | 100 | No effect: `Record` is synchronous |
| `WithFlushInterval(d)` | 1s | No effect: `Record` is synchronous |
| `WithCryptoErasure(b)` | false | Enable GDPR crypto-erasure |
| `WithKeyStore(ks)` | nil | Key store for crypto-erasure; required when it's on |
| `WithRetentionInterval(d)` | 24h | Retention enforcement interval (0 = off) |
| `WithArchiveSink(s)` | nil | Archive sink for retention |
| `WithDigestScheme(scheme)`, `WithKeyProvider(p)` | `plain` | Key the hash chain with HMAC |
| `WithCheckpoints(cfg)` | off | Signed checkpoints |
| `WithBasePath(path)` | `/chronicle` | URL prefix for the admin API |
| `WithDisableRoutes()` | false | Skip auto route registration |
| `WithDisableMigrate()` | false | Skip `Migrate` on `Start` |
| `WithConfig(cfg)`, `WithRequireConfig(b)` | | Replace the config, or require it in YAML |
| `WithGroveDatabase(name)` | `""` | Resolve a grove.DB from DI by name; empty uses the default DB. |
| `WithGroveKV(name)` | `""` | Resolve a grove KV store from DI by name; empty uses the default KV. |

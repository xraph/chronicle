This guide walks through a complete Chronicle setup: a PostgreSQL store, recording a few event types, querying, verifying the hash chain, generating a SOC 2 report, and serving the admin HTTP API through the Forge extension.

## 1. Install dependencies

```bash
go get github.com/xraph/chronicle@latest
go get github.com/xraph/grove@latest github.com/xraph/grove/drivers/pgdriver@latest
```

## 2. Record, query, verify and report

```go
package main

import (
    "context"
    "log"
    "os"
    "time"

    glog "github.com/xraph/go-utils/log"
    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"

    "github.com/xraph/chronicle"
    "github.com/xraph/chronicle/audit"
    "github.com/xraph/chronicle/compliance"
    "github.com/xraph/chronicle/scope"
    "github.com/xraph/chronicle/store"
    "github.com/xraph/chronicle/store/postgres"
    "github.com/xraph/chronicle/verify"
)

func main() {
    ctx := context.Background()
    logger := glog.NewDevelopmentLogger()

    // 1. Connect to PostgreSQL through Grove.
    drv := pgdriver.New()
    if err := drv.Open(ctx, os.Getenv("DATABASE_URL")); err != nil {
        log.Fatal(err)
    }
    db, err := grove.Open(drv)
    if err != nil {
        log.Fatal(err)
    }
    defer db.Close()

    // 2. Create and migrate the store.
    pgStore := postgres.New(db)
    if err := pgStore.Migrate(ctx); err != nil {
        log.Fatal(err)
    }

    // 3. Build Chronicle.
    adapter := store.NewAdapter(pgStore)
    c, err := chronicle.New(
        chronicle.WithStore(adapter),
        chronicle.WithLogger(logger),
    )
    if err != nil {
        log.Fatal(err)
    }

    // 4. Set up a scoped context.
    ctx = scope.WithAppID(ctx, "myapp")
    ctx = scope.WithTenantID(ctx, "tenant-acme")
    ctx = scope.WithUserID(ctx, "user-42")

    // 5. Record events. Each Record call writes the event before it returns.
    if err := c.Info(ctx, "login", "session", "sess-001").
        Category("auth").Outcome("success").Record(); err != nil {
        log.Fatal(err)
    }
    if err := c.Warning(ctx, "export", "report", "report-99").
        Category("billing").Outcome("success").Record(); err != nil {
        log.Fatal(err)
    }
    if err := c.Critical(ctx, "delete", "user", "user-7").
        Category("admin").Outcome("success").Reason("account closed on request").Record(); err != nil {
        log.Fatal(err)
    }

    // 6. Query recent events.
    result, err := c.Query(ctx, &audit.Query{Limit: 10, Order: "desc"})
    if err != nil {
        log.Fatal(err)
    }
    for _, ev := range result.Events {
        log.Printf("event %s: %s %s (%s)", ev.ID, ev.Action, ev.Resource, ev.Category)
    }

    // 7. Verify the hash chain.
    vReport, err := c.VerifyChain(ctx, &verify.Input{
        AppID:    "myapp",
        TenantID: "tenant-acme",
    })
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("verification: valid=%v verified=%d", vReport.Valid, vReport.Verified)

    // 8. Generate a SOC 2 report.
    engine := compliance.NewEngine(pgStore, pgStore, pgStore, logger)
    report, err := engine.SOC2(ctx, &compliance.SOC2Input{
        Period:      compliance.DateRange{From: time.Now().Add(-30 * 24 * time.Hour), To: time.Now()},
        AppID:       "myapp",
        TenantID:    "tenant-acme",
        GeneratedBy: "admin@acme.com",
    })
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("soc2 report %s with %d sections", report.ID, len(report.Sections))

    // 9. Export it as Markdown. (FormatPDF is declared but Export rejects it.)
    if err := engine.Export(ctx, report, compliance.FormatMarkdown, os.Stdout); err != nil {
        log.Fatal(err)
    }
}
```

## 3. Serve the admin API

The admin API registers its routes on a Forge router, so you serve it through the Forge extension rather than an `http.ServeMux`. The extension builds the compliance engine, the retention enforcer and the routes from the same store:

```go
app := forge.NewApp(forge.AppConfig{
    Name: "audit",
    Extensions: []forge.Extension{
        chronicleext.New(
            chronicleext.WithStore(pgStore),
            chronicleext.WithAuth("jwt",
                []string{"chronicle:read"},
                []string{"chronicle:write"},
                []string{"chronicle:admin"},
            ),
        ),
    },
})
if err := app.Run(); err != nil {
    log.Fatal(err)
}
```

The routes land under `/chronicle/v1/...`. See the [Admin API](/docs/subsystems/admin-api) for the list and the scopes each needs.

## Key points

- `store.NewAdapter(pgStore)` is always required before `chronicle.New` (see [Architecture](/docs/architecture)).
- The same `pgStore` value satisfies all three store arguments to `compliance.NewEngine`.
- Call `scope.WithAppID` (and usually `WithTenantID`) before recording or querying events.
- `Record` is synchronous. There's no batching to configure.
- For GDPR per-subject encryption, add `chronicle.WithCryptoErasure(true)` together with `chronicle.WithSealer(crypto.NewSealer(keyStore))`; without a sealer `New` fails. See [GDPR Erasure](/docs/guides/gdpr-erasure).
